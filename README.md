# Luna Catering Landing Page 🍱

Landing page statis untuk bisnis catering/nasi box yang dirancang untuk menampilkan menu unggulan, informasi bisnis, dan call-to-action pemesanan secara jelas dan responsif.

🔗 **Live Demo**  
https://lyant-dev.github.io/luna-catering-order-page/

---

## 📌 Tujuan Project

Project ini dibuat sebagai:

- Portofolio frontend web developer
- Contoh landing page UMKM / F&B terutama untuk Catering & Rice Box
- Latihan membangun website responsif dari nol menggunakan HTML, CSS, dan JavaScript

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**
- **Responsive Design**
- **Git & GitHub Pages**

- Menu populer
